AQUA ARCADE – statyczna strona HTML

Pliki index.html, style.css, script.js i katalog assets muszą być w jednym repozytorium.
GitHub Pages: Settings > Pages > Deploy from a branch > main > / (root).
Podgląd lokalny: otwórz index.html w przeglądarce.

Uwaga: koszyk jest demonstracyjny (nie obsługuje płatności), logowanie i inne strony docelowe nie mają backendu.
